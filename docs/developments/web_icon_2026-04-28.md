# Web Icon Development - 2026-04-28

## Objective

Add a small, elegant vector-style icon to the DEM Lab web viewer as both the browser tab favicon and the visual mark beside the viewer title.

## Assumptions

- The icon should communicate elevation model comparison and terrain analysis.
- The viewer is served by `scripts/lod_terrarium_viewer.py` from static files in `scripts/`.
- This development does not process geospatial input data and does not alter original data or generated experiment outputs.

## Inputs

- `scripts/lod_viewer.html`
- `scripts/lod_viewer.css`
- `scripts/lod_terrarium_viewer.py`

## Outputs

- `scripts/dem-lab-icon.svg`
- Updated favicon link in `scripts/lod_viewer.html`
- Updated title markup and styling in `scripts/lod_viewer.html` and `scripts/lod_viewer.css`
- Static SVG route in `scripts/lod_terrarium_viewer.py`

## Relevant Parameters

- Icon format: SVG
- View box: `0 0 64 64`
- Title display size: `24px`
- Favicon path: `/dem-lab-icon.svg`

## Notes

- The icon uses contour-line and terrain-mesh motifs to represent DEM refinement, comparison, and visualization.
- No rasterization, CRS conversion, metric calculation, downsampling, or simplification was performed.
